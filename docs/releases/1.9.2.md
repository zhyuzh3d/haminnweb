# HaminnUI 1.9.2 交互细节修正

2026-09-13 发布，Shell 清单版本码为 9。本版依据真机截图修正交互焦点框、Switch 圆点位置、Tab 版本信息和按钮对比度。

APK 与 UI 版本信息只在首页收藏 Tab 的顶部标题栏显示，切换到全部、开发、设置或支持后隐藏。支持页删除常见问题卡，设置页删除帮助卡。底部 Tab 图标容器始终透明，不再绘制选中背景。

按钮、链接、折叠标题和输入控件不再绘制点击或焦点外框，搜索框也不再因聚焦增加外圈。Switch 使用 54 × 32 轨道和绝对定位的 24px 圆点，左右各保留 4px，开启位移为 22px，轨道负责裁切，圆点不会越界。

普通、主操作、危险操作、禁用态、分段选择和弹层按钮均使用明暗主题语义色。自动检查要求主要按钮文字组合在两个主题下达到至少 4.5:1 对比度。
