# HaminnWeb 重构进度

2026-09-13：官网、Shell 模块、统一主题、核心流程和发布工具已实现；最新界面收口与上线证据见 `docs/releases/1.9.7.md`。

公开根继续为 `public/`。官网从占位页变为首页、下载、指南、隐私与支持；Shell 完成传统脚本模块化和统一主题，保留五个主导航与 Native 合同，补全 ZIP、备份导出、失败恢复和清楚的界面更新入口。

Shell 结构拆分先于功能/视觉变更完成。静态检查与 DOM 回归随之补齐，版本化制品采用确定性归档并校验完整源码闭包。APK 下载导入既有正式签名 1.8.0，不新建 Android release。

后续如果调整 Native 的清单签名、更新事务或在线运行策略，需要单独设计并交付兼容 APK；这些能力没有在本次前端重构中实现，也不作为官网部署的等待条件。
